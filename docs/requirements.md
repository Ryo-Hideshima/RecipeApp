# 要件定義書

## 概要
レシピを投稿・閲覧・検索できる学習用レシピ共有アプリ。ユーザーは材料・手順・写真付きでレシピを投稿し、他ユーザーはお気に入り登録やコメントで反応できる。フォロー機能によりお気に入りの投稿者を追いかけられる。

## 対象範囲

- 利用者: 受講生・個人が想定利用者だが、複数ユーザーが同時に利用することを前提に設計する
- 対象機能: 下記「機能一覧」を参照
- 対象外機能: 学習目的でのシンプル化のため実装しない機能がある。詳細は[features.md](features.md#対象外機能本アプリでは実装しない機能)を参照

## 機能一覧

詳細は [features.md](features.md) を参照。各機能の詳細な仕様は `features/` 配下の機能定義書を参照。

| No | 機能名 | 概要 |
|----|--------|------|
| 1 | ユーザー登録機能 | メール／パスワードでの新規登録、基本プロフィール設定 |
| 2 | ログイン機能 | ログイン／ログアウト |
| 3 | レシピ投稿機能 | タイトル・材料・手順・写真でのレシピ投稿、編集・削除 |
| 4 | レシピ一覧・検索機能 | 全レシピの一覧表示、キーワード／材料名検索、カテゴリ絞り込み |
| 5 | カテゴリ機能 | 固定のカテゴリマスタから、レシピへ複数カテゴリを付与 |
| 6 | お気に入り機能 | レシピのお気に入り登録／解除、お気に入り一覧表示 |
| 7 | コメント機能 | レシピへの感想・アレンジ提案のコメント |
| 8 | フォロー機能 | ユーザーのフォロー／フォロー解除、フォロー中／フォロワー一覧 |
| 9 | ユーザー検索機能 | ユーザー名・表示名でのユーザー検索 |

## 技術スタック

| レイヤー | 技術 |
|----------|------|
| フロントエンド | Next.js（TypeScript） |
| バックエンド | PHP（Laravel） |
| データベース | MySQL |
| 画像ストレージ | ローカルディスク（`storage/app/public`）。将来的にS3ディスクへ切り替え可能な構成にする |

## 用語定義

| 用語 | 説明 |
|------|------|
| レシピ | タイトル・材料・手順・写真からなる投稿の単位 |
| 材料 | レシピに紐づく食材と分量のリスト。材料名でのレシピ検索に使う |
| カテゴリ | 「和食」「デザート」等、事前に定義されたレシピの分類。1レシピに複数付与できる |
| お気に入り | レシピに対する好意的な反応・ブックマーク。1ユーザー1レシピにつき1回まで |
| フォロー | あるユーザーが別のユーザーの投稿を追いかけるための関係 |
| フォロワー | 自分をフォローしているユーザー |

## 非機能要件（簡易メモ）

- 認証: Laravel Sanctumによるトークンベース認証を想定（Next.jsフロントエンドからLaravel APIを呼ぶ構成のため）
- 画像ストレージ: レシピ画像・アイコン画像は当面ローカルディスク（`storage/app/public`）に保存し、DBには相対パスのみ保持する。将来S3ディスクへ切り替え可能な構成にしておく
- 学習目的のプロジェクトのため、可用性・スケーラビリティ等は最小限の考慮とする
