# 機能定義書: レシピ投稿機能

## 機能概要
ログインユーザーがタイトル・材料（複数）・手順（複数、順序付き）・写真（複数枚）を入力してレシピを投稿できる。投稿時にカテゴリ（複数可）を付与する（詳細は[category.md](category.md)）。自身のレシピは編集・削除できる。

## 事前条件／利用者権限
- レシピ投稿・編集: ログイン必須（編集は投稿者本人のみ）
- レシピ削除: ログイン済みかつ投稿者本人のみ

## 入力項目・バリデーションルール
| 項目 | 必須 | ルール |
|------|------|--------|
| タイトル（title） | 必須 | 最大100文字程度 |
| 材料（ingredients） | 必須（1件以上） | 各行「材料名」＋「分量」の組。材料名は最大50文字程度 |
| 手順（steps） | 必須（1件以上） | 各行が1手順。順序（step_number）を保持し、並び替え可能。1手順あたり最大500文字程度 |
| 写真（images） | 任意 | 複数枚添付可、1枚あたりのファイルサイズ・形式（jpg/png等）を制限 |
| カテゴリ（categories） | 任意 | 固定カテゴリマスタから複数選択可 |

## 処理フロー（正常系）
1. レシピ投稿画面でタイトル・材料・手順を入力し、任意で写真・カテゴリを選択
2. 写真がある場合、ローカルディスク（`storage/app/public`）にアップロードし、相対パスを取得
3. `recipes` テーブルにレシピレコードを作成
4. `ingredients` テーブルに材料を、`recipe_steps` テーブルに手順を、`recipe_images` テーブルに写真を、それぞれ `recipe_id` に紐づけて登録（材料・写真は`sort_order`、手順は`step_number`で順序を保持）
5. 選択されたカテゴリを `recipe_categories` テーブルに登録
6. 投稿完了後、レシピ詳細画面へ遷移

### 編集処理
1. レシピ詳細画面から投稿者本人にのみ表示される「編集」を選択
2. 投稿作成画面と同様の入力フォームに既存内容が反映された状態で表示
3. 変更内容で `recipes`・`ingredients`・`recipe_steps`・`recipe_images`・`recipe_categories` を更新

### 削除処理
1. レシピ詳細画面の「削除」を選択（投稿者本人にのみ表示）
2. `recipes` レコードを削除（関連する `ingredients`・`recipe_steps`・`recipe_images`・`recipe_categories`・`comments`・`favorites` も削除、ローカルディスク上の画像も削除）

## 異常系・エラーケース
- タイトル・材料・手順のいずれかが未入力 → 投稿不可としてエラー表示
- 画像アップロード失敗 → エラーメッセージを表示し再試行を促す
- 許可されていないファイル形式・サイズ超過 → アップロード前にクライアント側でエラー表示
- 他人のレシピを編集・削除しようとした場合 → 403エラーとしてアクセス拒否
