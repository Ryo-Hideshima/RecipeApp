# 機能定義書: ユーザー登録機能

## 機能概要
メールアドレスとパスワードによる新規ユーザー登録を行う。登録時・登録後に基本プロフィール（表示名・自己紹介・アイコン画像）を設定できる。

## 事前条件／利用者権限
- 新規登録: 未ログイン状態でも利用可能
- プロフィール編集: ログイン済みかつ本人のみ

## 入力項目・バリデーションルール
| 項目 | 必須 | ルール |
|------|------|--------|
| メールアドレス | 必須 | メール形式であること、登録済みメールアドレスとの重複不可 |
| パスワード | 必須 | 最低8文字以上 |
| 表示名（name） | 必須 | 最大50文字程度、他ユーザーとの重複は許容 |
| 自己紹介（bio） | 任意 | 最大160文字程度 |
| アイコン画像（avatar_path） | 任意 | 未設定時はデフォルトアイコンを表示 |

## 処理フロー（正常系）
1. 新規登録画面でメールアドレス・パスワード・表示名を入力し送信
2. サーバー側でバリデーション・メール重複チェックを実施
3. パスワードをハッシュ化して `users` テーブルに登録
4. 登録完了後、任意でプロフィール項目（自己紹介・アイコン）を設定
5. ログイン状態としてレシピ一覧画面へ遷移

## 異常系・エラーケース
- メールアドレス重複 → 登録エラーを表示し再入力を促す
- パスワード強度不足 → エラーメッセージを表示
