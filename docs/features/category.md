# 機能定義書: カテゴリ機能

## 機能概要
「和食」「デザート」等、事前に定義された固定のカテゴリマスタを用意し、レシピ投稿時に複数のカテゴリを付与できる。レシピ一覧・検索画面でのカテゴリ絞り込みに利用する。

## 事前条件／利用者権限
- カテゴリの閲覧・絞り込み: ログイン不要（全ユーザー）
- レシピへのカテゴリ付与: ログイン必須（付与できるのは投稿者本人のみ、レシピ投稿・編集時に行う）
- カテゴリマスタ自体の追加・編集: 本アプリのスコープ外（初期シーディングによる固定運用とする）

## 入力項目・バリデーションルール
| 項目 | 必須 | ルール |
|------|------|--------|
| カテゴリ（categories） | 任意 | 固定マスタから複数選択可。0件（未分類）も許容する |

初期シーディングで用意するカテゴリ例: 和食／洋食／中華／イタリアン／デザート／パン／サラダ／スープ／お弁当／飲み物

## 処理フロー（正常系）
1. レシピ投稿・編集画面でカテゴリ一覧をチェックボックス／チップ形式で表示
2. ユーザーが1件以上のカテゴリを選択（複数選択可）
3. レシピ保存時に `recipe_categories` テーブルへ選択されたカテゴリとの中間レコードを作成
4. レシピ一覧・検索画面でカテゴリを選択すると、該当カテゴリが付与されたレシピに絞り込まれる（[recipe-search.md](recipe-search.md)を参照）

## 異常系・エラーケース
- カテゴリ未選択でのレシピ投稿 → エラーにはしない（未分類として許容）
