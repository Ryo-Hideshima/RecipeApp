# 機能定義書: レシピ一覧・検索機能

## 機能概要
全ユーザーのレシピを新着順に一覧表示する。キーワード検索（タイトル）・材料名検索・カテゴリ絞り込みができる。未ログインでも閲覧・検索可能。

## 事前条件／利用者権限
- 一覧表示・検索: ログイン不要（全ユーザー）

## 入力項目・バリデーションルール
| 項目 | 必須 | ルール |
|------|------|--------|
| キーワード | 任意 | `recipes.title` に部分一致するレシピを検索対象とする |
| 材料名 | 任意 | `ingredients.name` に部分一致するレシピを検索対象とする |
| カテゴリ | 任意 | 固定カテゴリマスタから1件以上選択（複数選択時はOR条件） |

## 処理フロー（正常系）
1. レシピ一覧画面を開くと、全レシピが新着順（`created_at`降順）で一覧表示される
2. 検索ボックスにキーワードを入力して検索すると、タイトルに部分一致するレシピに絞り込まれる
3. 材料名で検索すると、該当する材料を持つレシピ（`ingredients`経由）に絞り込まれる
4. カテゴリチップを選択すると、該当カテゴリが付与されたレシピ（`recipe_categories`経由）に絞り込まれる
5. キーワード・材料名・カテゴリは組み合わせて絞り込み可能（AND条件）
6. レシピクリックでレシピ詳細画面へ遷移

## 異常系・エラーケース
- 該当レシピなし → 「該当するレシピが見つかりません」を表示

## 関連画面
- レシピ一覧画面
- レシピ詳細画面
