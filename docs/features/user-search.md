# 機能定義書: ユーザー検索機能

## 機能概要
ログインユーザーが、表示名でユーザーを検索できる。検索結果からプロフィール画面へ遷移し、フォローが可能。

## 事前条件／利用者権限
- ログイン必須

## 入力項目・バリデーションルール
| 項目 | 必須 | ルール |
|------|------|--------|
| 検索キーワード | 必須 | 1文字以上。`name`に部分一致するユーザーを検索対象とする |

## 処理フロー（正常系）
1. ユーザー検索画面の検索ボックスにキーワードを入力
2. `name` に部分一致する `users` レコードを検索（大文字小文字を区別しない）
3. 検索結果一覧をアイコン・表示名・フォローボタン付きで表示
4. ユーザー名または結果行クリックで対象ユーザーのプロフィール画面へ遷移
5. 結果一覧のフォローボタンから直接フォロー／フォロー解除が可能

## 異常系・エラーケース
- 該当ユーザーなし → 「該当するユーザーが見つかりません」を表示
- キーワード未入力での検索実行 → 検索を実行しない、またはエラー表示

## 関連画面
- ユーザー検索画面
- プロフィール画面

## 関連テーブル
- `users`
- `follows`（フォロー状態の表示・操作）
