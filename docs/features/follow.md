# 機能定義書: フォロー機能

## 機能概要
ログインユーザーが他ユーザーをフォロー／フォロー解除できる。フォロー中一覧・フォロワー一覧を確認できる。

## 事前条件／利用者権限
- フォロー／フォロー解除: ログイン必須。自分自身はフォロー不可
- フォロー中一覧／フォロワー一覧の閲覧: ログイン必須

## 入力項目・バリデーションルール
- 入力項目なし（フォローボタンの押下のみ）
- `follows` テーブルは `(follower_id, followee_id)` の組み合わせでUNIQUE制約を設け、重複フォローを防止する
- `follower_id <> followee_id` を満たすこと（自己フォロー禁止）

## 処理フロー（正常系）
1. プロフィール画面またはユーザー検索結果画面で対象ユーザーの「フォロー」ボタンを押下
2. `follows` テーブルに `follower_id`（自分）と `followee_id`（対象）のレコードを作成
3. フォロー解除は該当レコードを削除
4. プロフィール画面のフォロー中数／フォロワー数クリックで、それぞれの一覧画面へ遷移

## 異常系・エラーケース
- 自分自身へのフォロー操作 → 操作を無効化（ボタン非表示 or エラー）
- 既にフォロー済みのユーザーへの再フォロー → 冪等に扱う（エラーにしない）

## 関連画面
- プロフィール画面
- フォロー中一覧／フォロワー一覧画面
- ユーザー検索画面

## 関連テーブル
- `follows`
