# 機能定義書: ログイン機能

## 機能概要
メールアドレスとパスワードによるログイン・ログアウトを行う。Laravel Sanctumによるトークンベース認証を想定し、Next.jsフロントエンドはAPIトークンを保持してリクエストに付与する。

## 事前条件／利用者権限
- ログイン: 未ログイン状態で利用可能
- ログアウト: ログイン済みユーザーのみ

## 入力項目・バリデーションルール
| 項目 | 必須 | ルール |
|------|------|--------|
| メールアドレス | 必須 | メール形式であること |
| パスワード | 必須 | 未入力不可 |

## 処理フロー（正常系）
1. ログイン画面でメールアドレス・パスワードを入力し送信
2. サーバー側で認証情報を検証し、一致すればAPIトークンを発行
3. フロントエンドはトークンを保存し、以降のAPIリクエストの`Authorization`ヘッダーに付与
4. ログイン状態としてレシピ一覧画面へ遷移
5. ログアウト操作でトークンを失効させ、ログイン画面へ遷移

## 異常系・エラーケース
- メールアドレスまたはパスワード不一致 → エラーメッセージを表示（どちらが誤りかは特定させない）
- 未ログイン状態での認証必須APIへのアクセス → 401エラーとしてログイン画面へリダイレクト
