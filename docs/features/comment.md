# 機能定義書: コメント機能

## 機能概要
ログインユーザーがレシピに対して感想やアレンジの提案をコメントできる。投稿者本人だけでなく、第三者のユーザーもコメント可能。レシピごとのコメント数を表示する。

## 事前条件／利用者権限
- コメント投稿: ログイン必須（投稿者以外の第三者も可）
- コメント削除: ログイン済みかつコメント投稿者本人のみ

## 入力項目・バリデーションルール
| 項目 | 必須 | ルール |
|------|------|--------|
| コメント本文（content） | 必須 | 最大200文字程度 |

## 処理フロー（正常系）
1. レシピ詳細画面のコメント欄に感想やアレンジの提案を入力し送信
2. `comments` テーブルに `recipe_id`・`user_id`・`content` のレコードを作成
3. コメント一覧に新しいコメントが反映され、コメント数が更新される
4. コメント投稿者名クリックで投稿者のプロフィール画面へ遷移

### 削除処理
1. レシピ詳細画面のコメントから「削除」を選択（コメント投稿者本人にのみ表示）
2. `comments` レコードを削除

## 異常系・エラーケース
- コメント本文が空 → 投稿不可としてエラー表示
- 対象レシピが削除済み → コメント投稿不可、エラーメッセージ表示
- 他人のコメントを削除しようとした場合 → 403エラーとしてアクセス拒否

## 関連画面
- レシピ詳細画面

## 関連テーブル
- `comments`
