# 機能定義書: お気に入り機能

## 機能概要
ログインユーザーがレシピを「お気に入り」登録できる。投稿者本人だけでなく、第三者のユーザーも登録可能。1ユーザーにつき1レシピに対して1回まで。レシピごとのお気に入り数を表示し、自分がお気に入り登録したレシピの一覧を確認できる。

## 事前条件／利用者権限
- お気に入り登録／解除: ログイン必須（投稿者以外の第三者も可）
- 自分のお気に入り一覧の閲覧: ログイン必須、本人のみ

## 入力項目・バリデーションルール
- 入力項目なし（お気に入りボタンの押下のみ）
- `favorites` テーブルは `(recipe_id, user_id)` の組み合わせでUNIQUE制約を設け、同一ユーザーの重複登録を防止する

## 処理フロー（正常系）
1. レシピ一覧／レシピ詳細画面の「お気に入り」ボタンを押下
2. `favorites` テーブルに `recipe_id`・`user_id` のレコードを作成
3. 対象レシピのお気に入り数（`favorites`件数の集計）が更新され、画面に反映
4. 再度ボタンを押下（お気に入り解除）した場合、該当レコードを削除
5. お気に入り一覧画面では、自分が`favorites`に登録したレシピを新着順で一覧表示

## 異常系・エラーケース
- 既にお気に入り済みのレシピへの再登録 → UNIQUE制約違反を防ぐためAPI側で冪等に処理（トグル動作）
- 対象レシピが削除済み → お気に入り操作不可、エラーメッセージ表示
