# 画面イメージ確認用プロトタイプ

`docs/screens.md` の9画面を、依存ライブラリなしの単一 HTML ファイルでモック再現したもの。
本実装（Next.js + Laravel）を始める前に、画面遷移・レイアウト・表示要素の過不足を確認する用途。

## 使い方

`prototype/index.html` をブラウザで開くだけ。ビルド不要。

```sh
open prototype/index.html      # macOS
```

## 仕様・割り切り

- 画面遷移は URL ハッシュ（`#/recipes` など）で切り替え
- データはすべて JS 内のモック。**リロードすると初期状態に戻る**
- 認証はダミー（任意の入力でログイン成功、ログインユーザーは固定）
- 画像は CSS グラデーションのプレースホルダ
